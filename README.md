Aplicação web desenvolvida como parte da disciplina de Programação para Internet, utilizando o *framework* Laravel e focado em boas práticas de estruturação de banco de dados e rotas.

> ⚠️ **AVISO IMPORTANTE:** Este é um sistema estritamente acadêmico e amador.
---

## 🛠️ Tecnologias Utilizadas

- **Back-end:** [Laravel](https://laravel.com/) (PHP)
- **Front-end:** HTML5, CSS3, JavaScript e [Bootstrap](https://getbootstrap.com/)
- **Ícones:** [Ionicons](https://ionic.io/ionicons)
- **Banco de Dados:** Factories e Seeders para povoamento autônomo de dados fictícios.

---

## 💻 Estrutura do Projeto

- `public/css/styles.css`: Arquivo centralizador com os estilos customizados da aplicação.
- `database/seeders/`: Scripts de povoamento do banco de dados para testes imediatos.
- **Vibe Coding / Assistência:** Auxílio via IA focado no ajuste de classes do Bootstrap e no componente de paginação (`Paginator`).

---

### Pré-requisitos
- **PHP** (versão recomendada pelo Laravel do projeto)
- **Composer** instalado
- Banco de dados configurado (MySQL, SQLite ou PostgreSQL)
